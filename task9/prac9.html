Key Differences: LocalStorage vs SessionStorage

Feature localStorage sessionStorage
Lifetime Persists indefinitely until explicitly cleared via script or user cache wipe. Cleared automatically as soon as the tab or window is closed.
Scope Shared across all tabs and windows with the same origin (protocol, host, port). Scoped to the specific browser tab/window where it was created.
Storage Limit ~5MB - 10MB per origin depending on browser. ~5MB per tab session.
Server Communication Never sent to server with HTTP requests (unlike Cookies). Stays on client. Never sent to server with HTTP requests. Stays on client.
